# Маркеры режимов для Android

v3 учится различать два режима одной модели:

```text
<MODE_DIRECTOR>
<MODE_NARRATOR>
```

## Director

В начало системного prompt для вызова `director_action` добавить:

```java
"<MODE_DIRECTOR>\n"
```

Итог должен начинаться примерно так:

```text
<MODE_DIRECTOR>
Ты мастер DnD. СНАЧАЛА зафиксируй...
```

## Narrator

В начало системного prompt обычной генерации сцены добавить:

```java
"<MODE_NARRATOR>\n"
```

Итог:

```text
<MODE_NARRATOR>
Ты мастер настольной RPG...
```

## Почему это нужно

Без маркеров LoRA определяет режим только по косвенным различиям prompt. Это повышает риск:

- tool-call в повествовании;
- чрезмерно короткого рассказчика;
- обычного текста вместо Director action;
- смешения правил `CHECK_RESULT` и повествования.

До экспорта v3 в Android сравнение выполняется с теми же маркерами, поэтому приложение должно подавать их тоже.
